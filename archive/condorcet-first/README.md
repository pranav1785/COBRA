# Archived Condorcet-first formulation

This directory preserves the earlier COBRA report, experiments and results. It used a hierarchical Condorcet/Borda objective and oracle margin assumptions in its diagnostic budget. It is not the current Borda-only algorithm. Its reported experiments must not be mixed with the new results. The current entry point is the repository root README, and the active runner is `experiments/borda_study.py`.

The original remote version is also retained in normal Git history at `9ea4ce7ccac4eb9d6f251cd617cf863ebb843ac2`.
