# COBRA

**Condorcet-Or-Borda Reuse Algorithm**

LFHP project by Pranav Bhatnagar (ED23B037) and Praveen Kumar S (ED23B038).

A Condorcet-first learner that diagnoses non-existence and investigates whether diagnostic comparisons reduce the additional duels needed for a Borda fallback. This repository contains the experiment code, measured results, figures and LaTeX report.

The finite-horizon regret analysis assumes supplied positive separation bounds, known horizon, stationary reciprocal probabilities and independent comparisons. Real-data experiments use explicitly disclosed cyclic restrictions of PrefLib skating and ERS profiles.
